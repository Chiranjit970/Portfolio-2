# Resume Builder - Complete Usage Guide

## Quick Start (5 Minutes)

1. **Get Your OpenAI API Key**
   - Visit https://platform.openai.com/api-keys
   - Create a new API key
   - Copy it (you'll need it in step 3)

2. **Prepare Your Documents**
   - Export your LinkedIn profile as PDF
   - (Optional) Have your existing resume ready as PDF

3. **Generate Your Resume**
   - Open the application
   - Enter your API key
   - Upload your documents
   - Paste the job description
   - Click "Generate"

## Detailed Instructions

### Getting Your LinkedIn PDF

The LinkedIn PDF export contains all your profile information in a structured format:

1. Log into LinkedIn
2. Navigate to your profile page
3. Click the "More" button below your profile picture
4. Select "Save to PDF"
5. Wait for the download to complete
6. This file contains your experience, education, skills, and summary

**Pro Tip:** Update your LinkedIn profile before exporting for best results!

### Choosing the Right Information

**What to Include in Your Upload:**

✅ **LinkedIn PDF** (Recommended)

✅ **Existing Resume PDF** (Optional)

**Using Both:** Upload both for maximum information and best results!

### Writing an Effective Job Description

The job description is crucial for ATS optimization. Here's what to include:

**Essential Elements:**
- Job title
- Required qualifications
- Preferred qualifications
- Responsibilities and duties
- Required skills and technologies
- Nice-to-have skills
- Company information (optional)

**Example:**
```
Senior Software Engineer

We're seeking an experienced Senior Software Engineer to join our team...

Requirements:
- 5+ years of software development experience
- Strong proficiency in JavaScript, React, and Node.js
- Experience with cloud platforms (AWS, Azure)
- Bachelor's degree in Computer Science or related field

Responsibilities:
- Design and implement scalable web applications
- Lead technical discussions and code reviews
- Mentor junior developers
...
```

**Tips:**
- Copy the entire job posting (don't summarize)
- Include bullet points and formatting
- Don't edit the requirements
- More detail = better keyword matching

### Understanding ATS Scores

#### Overall ATS Score (Target: 90+%)
- Measures general compatibility with ATS systems
- Based on formatting, structure, and content
- Higher score = better chance of passing initial screening

#### Keyword Match (Target: 85+%)
- How well your resume matches job requirements
- Calculated from job description keywords
- Natural integration is key (no keyword stuffing)

#### Formatting Score (Target: 95+%)
- Technical compatibility assessment
- Checks for ATS-friendly elements
- Simple formatting scores higher

### Export Formats Explained

#### PDF (Recommended)
- **Pros:** Universal compatibility, preserves formatting, professional
- **Cons:** Some older ATS may struggle with complex PDFs
- **Use For:** Most job applications, email submissions

#### HTML
- **Pros:** Easily customizable, web-friendly, lightweight
- **Cons:** Not directly submittable, requires conversion
- **Use For:** Online portfolios, personal websites, further editing

#### Plain Text
- **Pros:** Maximum compatibility, smallest file size
- **Cons:** No formatting, basic appearance
- **Use For:** Email body, ATS systems that prefer text, backup format

### Common Questions

**Q: Do I need both LinkedIn and resume PDFs?**
A: No, one is sufficient. Both provide best results.

**Q: How much does this cost?**
A: The app is free. OpenAI API costs ~$0.10-0.30 per resume generation.

**Q: Is my data stored?**
A: No. Everything is processed locally. Your API key and files are never saved.

**Q: Can I edit the generated resume?**
A: Yes! Download HTML version and edit in any text editor or regenerate with different inputs.

**Q: How accurate is the ATS score?**
A: It's an estimate based on industry standards. Test with actual ATS checkers for confirmation.

**Q: Will this pass AI detection?**
A: The system is designed to write in natural, human-like language with varied sentence structures and authentic phrasing.

**Q: Can I generate multiple versions?**
A: Yes! Simply change the job description and regenerate for different positions.

**Q: What about privacy?**
A: Your data is only sent to OpenAI for processing. We don't store or transmit anything else.

### Best Practices

#### Content Writing
- ✅ Use action verbs (achieved, improved, led)
- ✅ Include specific metrics (increased by 30%)
- ✅ Focus on achievements, not duties
- ✅ Tailor to each job application
- ✅ Keep bullet points concise (1-2 lines)
- ✅ Use consistent tense
- ❌ Avoid personal pronouns (I, me, my)
- ❌ Don't use generic phrases
- ❌ Skip irrelevant experience
- ❌ No typos or grammar errors

#### Formatting
- ✅ Simple, clean layout
- ✅ Standard fonts
- ✅ Consistent spacing
- ✅ Clear section headers
- ✅ Standard date formats
- ✅ Professional appearance
- ❌ No tables or text boxes
- ❌ No images or graphics
- ❌ No fancy fonts
- ❌ No multiple columns

#### Keywords
- ✅ Use naturally in context
- ✅ Include variations
- ✅ Spell out acronyms once
- ✅ Match job description terms
- ✅ Include technical skills
- ✅ Add soft skills appropriately
- ❌ Don't keyword stuff
- ❌ Avoid overusing terms
- ❌ Don't force unnatural phrasing

### Troubleshooting

#### PDF Won't Upload
**Possible Causes:**
- File is corrupted
- File is password-protected
- File is too large
- Wrong file format

**Solutions:**
- Re-export from LinkedIn
- Remove password protection
- Compress PDF file
- Verify file is actually PDF

#### Generation Fails
**Possible Causes:**
- Invalid API key
- Insufficient credits
- Network issues
- Empty job description

**Solutions:**
- Verify API key
- Check OpenAI account credits
- Check internet connection
- Add detailed job description

#### Low ATS Score
**Possible Causes:**
- Missing keywords
- Vague job description
- Incomplete source documents
- Template mismatch

**Solutions:**
- Use detailed job description
- Add more information to LinkedIn
- Try different template
- Review suggestions and adjust

#### Export Problems
**Possible Causes:**
- Browser pop-up blocker
- Download permissions
- Insufficient disk space

**Solutions:**
- Allow pop-ups for site
- Check browser settings
- Free up disk space
- Try different browser
